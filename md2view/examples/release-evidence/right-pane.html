发布成功，为什么用户还装不上？

把“命令执行完了”推进到“陌生用户获得可工作的结果”。点击右侧内容，回到左侧原文核证。

EVIDENCE

三种证据，回答三个问题

本地测试通过，不能证明公开安装已经可用。

DELIVERY STATE

命令成功与交付完成之间

ARTIFACT

同一个包走到底

哈希证明文件一致，不证明功能正确。

为什么不能重新打包？

验证后重新打一个包，会让原先的验证证据失去对应对象。

REAL USE

安装行为也是产品的一部分

已有用户的配置需要保留。新 provider 能只读查询就先只读查询，不改写其他 provider 的状态或现有安装。
NEXT ACTION

失败在哪一段，就回到哪一段

测试或命令失败回到实现或检查路径
本地测试失败回到实现
指定版本不可读检查分发状态
包可下载，命令失败检查安装环境
命令成功，没有需要的结果检查实际使用路径
未知不是零。一次成功不等于所有环境都支持；订阅账号、系统版本和使用场景缺证据时，要明确列出。
