# 概念 → 画面配方

每个讲解镜头先问：这个概念的**动作**是什么（拆开、穿过、筛选、累积、比较、循环……），再从下表挑对应配方。配方里的代码片段都放在 `render(el, u, d)` 里，`u` 是镜头内秒数。元素在 `init` 里用 `el.querySelector` 缓存一次。

## 镜头密度清单（每个讲解镜头都要满足）

- **主视觉**：一个大东西（卡片、网络图、网格、图表），全部内容合起来占安全区宽度或高度 ≥ 60%，大致居中。不要一屏只有一行字。
- **骨架 1 秒内立起来**：节点、外框、坐标轴、格子在镜头开头一次出齐，后面的时间给主角移动和状态变化。
- **主角在场**：本片主角（那句话 / 那笔钱 / 那颗光子）以当前形态出现在主视觉里。
- **1–3 个标注**：标签胶囊、小数字、箭头说明，字号 ≥ 24 px。
- **一个持续运动**：扫描线、流动光点、计数器、呼吸光晕、缓慢漂移。字幕停留期间画面也不能完全静止。
- **动作按字幕节奏发生**：字幕说到什么，什么就在那一刻动起来（同一时刻加 `sfx`）。

## 配方

| 概念动作 | 画面 | 关键写法 |
|---|---|---|
| 加密 / 编码 / 转换 | 卡片里的明文被一条扫描线从左往右刷成乱码 | 见 `shots.example.js` 的 `pack`：`k = floor(len * cubic(prog(u,a,b)))`，前 k 个字符换成 `rng` 生成的乱码；扫描线 `left = x0 + k * charW` |
| 传输 / 路径 / 流程 | 开头 1 秒内节点和路线全部出现；主角卡片沿路线走，到达哪个节点就点亮哪个；路线上点状虚线持续流动 | 见 `shots.example.js` 的 `net`：底层路线 `EX.drawPath(route, expoOut(prog(u,.2,1)))`，已走过的一段 `EX.drawPath(done, p)`，主角 `path.getPointAtLength(L*p)`，流动 `dashFlow(flow, u, 60)` |
| 检查 / 筛选 / 闸门 | 一排拱门或竖条，主角卡片依次穿过，每过一道亮一个绿勾 | 卡片 `x = lerp(x0, x1, cubic(prog(u, a, b)))`；第 i 道门在卡片经过时 `EX.pop(check_i, u, tPass_i)` |
| 拆分 / 切块 | 一句话大字居中 → 字之间裂开缝隙变成彩色块，块下浮出编号 | 每块 `left = springTrack(u, [[0, 合拢位置], [a, 分开位置]])`；颜色 `EX.TOKEN_COLORS[i % 8]`；编号 `EX.fadeUp(id_i, u, a + .3 + i*.08)` |
| 变成数字 / 向量 / 特征 | 每个块下方垂下一串彩色短条 | 每块 8–12 根短条，高度 `rng(seed)`，`scaleY` 随 `expoOut(prog(u, a + i*.06, …))` 生长 |
| 相似 / 聚类 / 空间 | 散点云，几团不同颜色，团里有词标签 | 点位 = 团中心 + `rng` 高斯偏移，点 `EX.pop` 依次出现；整体 `rotate(u*2deg)` 慢转作为持续运动 |
| 层层加工 / 深度 | 一叠横条（第 1 层…第 N 层），一束光从下往上穿过，右侧计数“第 n 层” | 光束 `y = lerp(底, 顶, prog(u,a,b))`；当前层 `box-shadow` 亮起；计数 `EX.num(el, N, prog(u,a,b))` |
| 关联 / 注意力 / 依赖 | 一排块之间画彩色弧线，从当前块连向之前的块 | SVG `<path d="M x1 y Q (x1+x2)/2 y-h x2 y">`，弧高随距离增加；逐条 `EX.drawPath(arc_i, cubic(prog(u, a + i*.12, a + i*.12 + .6)))` |
| 规模 / 数量级 | 大号计数器滚到一个巨大的数，旁边一格格单元同时点亮 | `EX.num(el, 2e11, expoOut(prog(u,a,b)))`；格子 `opacity = prog(u, a + i*.03, …)` |
| 概率 / 排名 / 比较 | 横向条形图，条一根根长出，最高的一根描边高亮，然后被“选中”放大 | 条宽 `w = W * v * expoOut(prog(u, a + i*.1, …))`；赢家 `EX.pop` + 放射光芒（多根短线 `rotate(i*30deg)` 随 u 外扩） |
| 循环 / 逐个生成 | 一排块的末尾不断接上新块，左边一个处理器每轮闪一次 | 第 k 块在 `a + k*step` 时 `EX.pop`；处理器亮度 `pulse(u - a, step)` |
| 缓存 / 存储 / 积累 | 一个大格子容器，每轮新增一列彩色小方块 | 第 k 列 `opacity = u > a + k*step ? 1 : 0`，新列 `EX.pop` |
| 距离 / 地理 | 半透明圆形地球（圆 + 两三条经纬椭圆），一条弧线从一点画到另一点 | 地球 = `<circle>` + `<ellipse>`，整体径向渐变；弧线 `EX.drawPath`；起终点小圆点 `pulse` 呼吸 |
| 速度 / 介质 | 一条管道横穿屏幕，管内光脉冲飞过，脉冲拖尾 | 管道 = 两条平行线 + 半透明填充；脉冲 `x = ((u*速度) % 跨度)`，拖尾用 `linear-gradient` 宽条 |
| 界面里发生的事（输入、聊天、支付） | 一张简化的 UI 卡片（顶栏三个圆点、输入框、气泡） | 打字 `EX.type(el, str, u, a, cps)`；按钮按下 `scale(1 - .18*exp(-14*(u-a)))`；流式回答同打字，末尾光标闪烁 |
| 拼装 / 上下文 | 几张小卡片（系统提示、历史、问题）从两侧飞入，拼成一张长卡 | 每张 `translateX = lerp(±600, 0, expoOut(prog(u, a + i*.3, …)))` |
| 回扣 / 结局 | 背景整体换成和答案有关的画面（蓝天、绿叶、城市夜景），答案卡片浮在上面 | 在镜头 html 里放一个 `inset:0` 的全屏层，`opacity = cubic(prog(u, a, a + 1.5))`，用 CSS 渐变画天空，`ICON.sun` 放大当太阳 |
| 小结 | 底部一条横向时间轴，3 个节点依次亮起，每个节点“数值 + 一句话” | 节点 `EX.pop(node_i, u, a + i*.6)`，连线 `EX.drawPath` |

## 主角跨镜头

同一个主角连续出现在两个镜头里时：让上一个镜头最后一帧和下一个镜头第一帧里主角的位置、大小完全一样，下一个镜头写 `enter: 'cut'`。观众看到的是主角不动、周围的东西换了，这比叠化更连贯。每章至少一次这样的衔接。

## 禁止

- 一屏只有一段文字或一个标题的讲解镜头（只允许出现在钩子、承诺、片尾）。
- emoji 当图标（无头浏览器可能没有 emoji 字体），用 `ICON.xxx`。
- 画面上复述字幕原文。字幕说“发生了什么”，画面上只放短标签和数字。
- 编造精确数字。没有可靠来源的写量级（“几十到上百层”“约 2000 亿次”），示意值在画面上标“示意”。
- 用 `Math.random()`、`Date.now()`、`setTimeout`、CSS `animation` / `transition`：渲染器逐帧跳时间，这些都会错帧。只用 `u` 和 `rng(seed)`。
