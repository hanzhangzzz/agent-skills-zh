# 范例拆解：《回车之后的 3 秒》

一支社区流传的、用代码写出来的高质量讲解片（Opus 5.5 生成，126 s，1920×1080 60fps，无旁白，配乐 + 音效，中文字幕承担解说）。下表只概括每段字幕讲了什么，不转录原文。本 skill 的版式、HUD、节奏规则都从它反推而来。这里拆它**为什么好**，供写分镜时对照。不要照抄它的镜头，换题目后照它的结构走。

## 1. 一句话结构

> 把一个日常瞬间（按下回车）放慢成一段旅程，让一个具体主角（问题“天空为什么是蓝色的？”）走过每一站。仪表（计时器 0.000 → 3.000 s）告诉观众走到了哪、还剩多少。每站只讲一个概念，最后用答案本身回扣开头。

四个部件缺一不可：

| 部件 | 范例里 | 作用 |
|---|---|---|
| 日常瞬间（钩子） | 输入框里打字、按下 Enter 键帽特写 | 观众 1 秒就认出来，不需要背景知识 |
| 主角 | 那句问题文字，每站换一种形态：明文 → 乱码 → 光脉冲 → token 块 → 向量条 → 答案 | 观众一直跟着同一个东西走，不会迷路 |
| 仪表 | 顶部计时器 + 0–3 s 进度条 + 右上“慢放 ×2,500” | 进度感、悬念（“才 0.24 秒？”）、把章节串成一条线 |
| 回扣 | 结尾背景变成蓝天和太阳，答案卡片浮在天上 | 用问题的内容收尾，情绪落点 |

## 2. 时间线

| 时间 | 章节（HUD 标签） | 画面 | 字幕讲了什么（概括） |
|---|---|---|---|
| 0–8 | 钩子（无 HUD） | 输入框逐字打出问题 → Enter 键帽按下 | 交代动作：向 AI 提问、按回车；点出“答案只要约 3 秒” |
| 8–14 | 承诺（无 HUD） | “回车之后的 3 秒”大字 + 环形计时器 0.000 s + 散落粒子 | 宣布手法：把这 3 秒放慢来看 |
| 14–24 | 01 打包 · 加密 | HTTP 请求卡片（POST /chat、Content-Type、“message”: 问题原文）→ 一条竖向扫描线扫过，左边变十六进制乱码，右上落锁 | 问题被装进 HTTP 请求；TLS 加密后截获也只是乱码 |
| 24–36 | 02 穿越网络 | 设备 → 路由器链路逐个点亮 → 镜头钻进光纤管道，光脉冲飞过 → 半透明地球上一条弧线 | 途经十几台路由器；在光纤里变成光脉冲，速度约为真空光速的 2/3 |
| 36–50 | 03 抵达数据中心 | 三道拱门“解密 / 验证身份 / 检查请求”，问题卡片依次穿过 → 调度器 → GPU 机柜列；再拼上系统提示和历史对话 | 入口三道检查；调度到运行模型的 GPU；问题拼在系统提示和历史对话之后 |
| 50–58 | 04 切分 token | 问题大字居中 → 裂成彩色 token 块，块下标编号 | 模型读的是 token：词、字或字的一部分，各有编号 |
| 58–66 | 05 变成向量 | 每个 token 下方垂下一串彩色短条 → 散点云“意义空间”，近义词聚成团 | 编号换成几千维的向量；向量是词在“意义空间”里的坐标 |
| 66–80 | 06 Transformer | token 列向上穿过一层层发光柱，右侧“第 22 层 → 第 80 层”计数 → token 之间画注意力弧线 | 进入几十到上百层的 Transformer；每个 token 回看前文，即“注意力”；整段输入并行读完叫“预填充” |
| 80–86 | 07 GPU 并行计算 | 8 块 GPU 芯片网格逐个点亮，计数器滚到 200,000,000,000 次运算 | 模型拆到多块 GPU 上；每个 token 约 2000 亿次运算 |
| 86–96 | 08 预测下一个 token | 候选词概率条形图（因为 62%、天空 8%…）→ “因为”被选中，放射光芒 | 为词表里每个 token 打分；按概率选出答案的第一个 token |
| 96–108 | 09 逐个生成 | 左边 8 层堆栈，一束光从下往上走；中间“KV 缓存”格子逐行变长；底部 token 串一个个变长；右边一部手机 | 新 token 接到末尾再算下一个；KV 缓存免去重算；每个 token 十几到几十毫秒 |
| 108–116 | 10 流式返回 | 聊天窗口里答案逐字长出来，末尾一个光标 | token 流式发回逐个显示；遇到“结束” token 回答完成 |
| 116–122 | 回扣 | 计时器停在 3.000；背景从粉彩渐变成蓝天白云和太阳；底部三点小结：0.08 秒 抵达数据中心 / 0.45 秒 生成第一个 token / 3 秒 回答完整显示 | 把 3 秒压成一句话：穿过光纤和神经网络，再一个字一个字回来 |
| 122–126 | 片尾 | “回车之后的 3 秒”大字 | — |

计时器的走法：标题时 0.000；打包 0.001–0.004；网络 0.01–0.08；数据中心 0.10–0.23；token / 向量 0.24；Transformer 0.26–0.41；GPU 0.42–0.44；预测 0.44–0.45；逐个生成 0.45–1.6；流式 1.6–3.0。慢放倍数从 ×2,500 降到 ×5。**片子的时间按概念的重要性分配，不按真实时间分配**；右上的慢放倍数把这件事公开告诉观众，它本身就是看点。

## 3. 它为什么好（可迁移的规则）

1. **主角一直在画面里**。每一章的主视觉都是“主角此刻的形态”，不是一张孤立的示意图。换章时主角变形，不换题。
2. **一章一个概念，第一次出现时命名**。字幕里用引号 + 章节色标出术语（“TLS 加密”“token”“注意力”），之后画面就用这个名字的标签。
3. **章节色贯穿**。HUD 编号圆点、进度条这一段、字幕关键词、本章主视觉的描边都用同一种颜色，换章换色。
4. **每个镜头三层**：一个大主视觉（卡片 / 图 / 网格，占画面 40–60%）、1–3 个小标注（标签、数字、箭头说明）、一个持续在动的东西（扫描线、流动光点、计数器、呼吸光晕）。没有任何一秒是完全静止的。
5. **隐喻具体到能画出来**：加密 = 扫描线把明文刷成乱码；光纤 = 管子里飞的光；注意力 = token 之间的弧线；KV 缓存 = 一格格填满的方块；预测 = 概率条形图；并行 = 一排芯片同时亮。
6. **数字有量级依据**：20 万公里/秒、真空光速的 2/3、几十到上百层、约 2000 亿次运算、十几到几十毫秒。示意值（如“示意 8 层”）在画面上直接标出来。
7. **字幕是一句完整的人话**，一屏一句，18–24 字，停留 4–5 s。它说“此刻发生了什么”，不复述画面上的标签。句式是“动作 + 后果”：先说此刻发生了什么，再用一个后果让观众明白它为什么重要（例：先说“数据被加密”，再说“所以半路截获也只是乱码”）。术语只在第一次出现时加引号。
8. **结尾回扣 + 小结**：用问题的答案做最后的画面（蓝天），再用 3 个时间点把全片压成一行，最后停在片名。

## 4. 视觉规格（house style，模板已内置）

这是范例的画风，也是模板的保底世界。它适合没有实体的系统流程；题目有实体、有路线、跨尺度时，按 `worlds.md` 换世界，下面的结构规则照用。

- 背景：淡紫 → 淡蓝 → 薄荷 → 杏色的大面积渐变 + 柔光色块缓慢漂移 + 极淡点阵。
- 卡片：白色半透明、圆角 24–28、柔和蓝紫阴影；重点卡片加 2–3 px 章节色描边。
- 文字：深海军蓝 `#1E2240` 为主，次要灰蓝 `#5D6385`；粗黑体（Noto Sans SC 700/900）；代码与数字用等宽字体。
- 强调色 8 个：蓝 `#3B6CF6`、紫 `#7C4DFF`、粉 `#E6458B`、青 `#0EA5C6`、绿 `#14B27A`、橙 `#F59E0B`、红 `#EF4444`、靛 `#4F46E5`。token 块按顺序循环取色。
- HUD：左上章节胶囊（编号圆点 + 章节名），正上计时胶囊 + 进度条（每章一段颜色），右上慢放倍数；底部白色字幕胶囊。
- 动效：卡片弹簧落定、文字淡入上移、路径描边生长、计数器滚动；镜头之间 0.5 s 柔和叠化，同一主角跨镜头时直接接（continuity cut）。

## 5. 换题时怎么套

| 题目类型 | 日常瞬间 | 主角 | 仪表 |
|---|---|---|---|
| 一个系统内部发生了什么（AI 回答、扫码支付、打开网页、发一条消息） | 按下按钮那一刻 | 那条请求 / 那笔钱 / 那条消息 | 真实耗时（秒、毫秒） |
| 一个东西从哪来（一杯咖啡、一度电、一颗芯片） | 喝下第一口 / 按下开关 | 那颗咖啡豆 / 那份电能 | 天数、公里数 |
| 一个过程怎么发生（光合作用、伤口愈合、疫苗起效） | 晒太阳 / 划破手指 | 一个光子 / 一个细胞 | 时间（秒到天） |
| 一个尺度有多大（从人到原子、从地球到银河） | 看一眼自己的手 | 镜头本身 | 尺度（10ⁿ 米） |
| 一段历史怎么演变（一座城、一项技术） | 今天的街景 | 同一个街角 / 同一个零件 | 年份 |

仪表是时间（s / ms / min / h / 天 / 年）时，右上角自动显示“慢放”或“快进”倍数；不是时间（公里、层、尺度）时不显示。
