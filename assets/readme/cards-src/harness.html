输入 · 触发

/harness 这轮重点关注静默数据丢失
和缺少验证的代码路径

bash inspector.sh
bash worker-reviewer.sh --loop

TODO.md 看板格式

- [ ] [待领取] 任务标题
      inspector-note: 补充信息
- [ ] [进行中] 任务标题
      started: YYYY-MM-DD HH:MM by worker
- [ ] [待审查] 任务标题
- [ ] [被拒绝] 任务标题
      reviewer-note: 打回原因

[待领取] → 未领取（你可以领取）
[进行中] → 你正在做（别人不要动）
[待审查] → 你完成了，交给 Reviewer
[被拒绝] → Reviewer 打回来了，你需要重新修

领取顺序：Priority 0 > 1 > 2 > 3；先 [被拒绝] 再 [待领取]
