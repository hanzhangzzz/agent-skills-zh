agent-chrome登录态 Chrome · CDP
每个账号一个 profile、一个固定 CDP 端口；正式版 Chrome 由它 up/down，agent-browser 和 Playwright 只连端口

输入 · 触发

python3 scripts/agent_chrome.py add x-main --sites x.com,twitter.com --default-for x
python3 scripts/agent_chrome.py up x --headless
agent-browser --cdp 19304 open https://x.com/home
python3 scripts/agent_chrome.py down x-main

输出

{"profile":"x-main","port":19304,
 "ws":"ws://127.0.0.1:19304/devtools/browser/…",
 "pid":20107,"headless":true,"reused":false}

~/.chrome-profiles/<站点>-<别名>/   登录态只存这一份
seed --from-main   从主 Chrome 只读引导 cookie
有头窗口后台打开，不抢焦点；down 走 Browser.close 落盘 cookie
输出结构来自 agent-chrome/SKILL.md（macOS；正式版 Chrome、Python 3、Node ≥ 22）
