PR #8 上的真实评论（GLM-5.3）

**"范围为空（例如只改了 DO.md）"与上一行的机械规则矛盾**
失败场景：DO.md 随分支进入 diff → diff 非空 → 捷径分支永不触发
复现：git diff <base>...t --stat → DO.md | 1 +

→ 开发者修复 push → 增量审查（sticky）：
无代码改动 —— 范围只含两个 *.md，按捷径分支只更新 sticky
"修正逻辑矛盾"成立 —— 本条 sticky 正是新捷径分支的首次真实触发
发现 0 条重复评论；改规范 = 改 .github/ci-review.md，下次 push 生效
