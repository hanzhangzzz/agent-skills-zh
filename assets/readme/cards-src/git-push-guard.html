git-push-guard纯 hook · 分支保护
Claude Code hook 对 Agent 直推 main/master 请求确认；不是 Git 服务端保护

输入 · 触发

Agent 执行：

git push origin main

（PreToolUse hook 匹配 Bash）

hook 返回格式

permissionDecision: "ask"

匹配到 Agent 的 Bash 工具执行 git push 时，
对直推 main/master 请求确认。

支持按仓库路径放行。
独立终端操作和服务端保护不由此 hook 负责。
返回格式来自 git-push-guard/block-push-default-branch.sh；此卡不是实际权限弹窗
