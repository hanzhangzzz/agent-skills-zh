xiaohongshu搜索 → 本地知识材料
一个 Skill 路由到确定性脚本：专用登录、搜索、翻收藏夹、单篇或批量下载、本地召回，以及存成平台草稿

输入 · 触发

搜小红书上的 AI 游戏开发经验
把我收藏里关于 UI 的几篇下载下来
下载这篇笔记并提取口播
把这段文案和两张图存成小红书草稿

输出结构

xhs.py login / search / albums / collected / fetch / recall / draft

用户数据目录/accounts/<账号>/
├── library.sqlite    搜索记录与知识索引
└── notes/<帖子ID>/
    ├── source.json
    ├── note.md
    ├── image-001.jpg  图文按需下载
    ├── video.mp4      视频按需下载
    └── video.txt      口播按需转录

collected 按标题预筛收藏，选篇交给 Agent；
fetch 可一次传多个 ID 批量下载；
draft 支持文字/图文/视频三种模式，
草稿存在专用浏览器本地，不发布；
召回为关键词检索，OCR 与向量检索未实现
