audio-inbox文件夹 → mp3
把一个文件夹变成音频收件箱：放进 m4a、wav、视频等，launchd 后台自动转 mp3，原文件移到 _done；输出放进网盘同步目录即自动同步

输入 · 触发

bash scripts/install.sh --inbox ~/音频收件箱 --out ~/音频mp3
bash scripts/selftest.sh

之后把文件拖进收件箱：
~/音频收件箱/Lion2.m4a
~/音频收件箱/周三/nopns44m.m4a

输出

~/音频mp3/
├── Lion2.mp3          450 秒录音，约 165kbps
└── 周三/nopns44m.mp3
~/音频收件箱/_done/    原文件移到这里，不删除

audio-inbox.log：
10:29:41 转换：Lion2.m4a
10:29:43 ✅ Lion2.m4a → …/Lion2.mp3
10:29:46 ✅ 周三/nopns44m.m4a → …/周三/nopns44m.mp3
