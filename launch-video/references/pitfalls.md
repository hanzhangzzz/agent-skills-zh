# 已踩过的坑

每条都来自真实渲染失败；动手前扫一遍，交付前按“自检”复查。

| 症状 | 根因 | 做法 |
| --- | --- | --- |
| 上一幕的文字残留在后面几幕 | 子元素 `visibility: visible` 会覆盖父元素的 `hidden` | 场景用 `display` 开关；子元素只在透明时设 `hidden`，其他时候设空字符串继承 |
| 字体没生效，渲染报 `ERR_FILE_NOT_FOUND` | `fonts.css` 里的 `url()` 相对 CSS 文件解析，不相对页面 | 用 `scripts/fetch_fonts.py` 生成，页面 `<link href="fonts/fonts.css">` |
| 逐帧画面跳动、seek 回退后状态错乱 | `render(t)` 依赖上一帧状态或 `setTimeout` | 每个样式都由 `t` 直接算出；需要的 DOM 结构在初始化时一次建好 |
| 录屏素材某些帧是空白 | 切换 `img.src` 后图片未解码就截图 | 预加载全部帧（模板 `preloadFrames`）；`render.mjs` 截图前会等待解码 |
| 录屏素材顶部带旧字幕条 | 复用了已加字幕的演示片段 | 抽帧时 `crop` 掉字幕区；抽一帧放大确认后再批量处理 |
| 视频结尾回到第一幕 | 播放循环在录制时继续运行 | 录制时由 `window.__recording` 停用循环；时间只由 `__seek` 驱动 |
| 深色幕里角标不见 | 跨幕元素写死了颜色 | 角标使用 `currentColor`，由引擎按当前幕切换 |
| 画面上文字换行难看或溢出 | 用系统回退字体排版，或文案过长 | 先确认字体已加载；标题 ≤ 8 个词；用静帧检查每一幕 |
| 音效响了，画面晚 0.25s 才动 | 转场用 ease-in-out 缓动，且圆的半径远大于盖满画面所需，开头几帧几乎看不出变化 | 转场与进场用 `expoOut`，从音效时间点起步，半径取画面对角线一半；用 `scripts/check_sync.py` 复查 |
| 一组元素整块出现，几次音效却没有画面对应 | 整组共用一个 `rise` | 拆成逐个元素，起点对齐各自的音效 |
| 数字/输出“看起来像真的”但不是 | 为了画面好看临时编造 | 数字只用已核实结果；格式展示按源码写并标注示意 |
| three.js 页面一直不就绪，`render.mjs` 超时 | 用 `file://` 打开时 ES module 被 CORS 拦截 | `render.mjs` 已改为本机 HTTP 服务；自己预览时也用 `python3 -m http.server`，不要双击打开 |
| 3D 截图贴图发灰、偏色 | 纹理没设 sRGB，又被色调映射处理 | `texture.colorSpace = THREE.SRGBColorSpace`，材质设 `toneMapped: false` |
| 粒子、噪点、故障每次渲染结果不同 | 用了 `Math.random()` 或逐帧累积状态 | 只用 `rng(seed)`；随帧变化的随机用 `rng(Math.floor(t × 帧率))`；运动写成 t 的闭式函数 |
| 中文标题回退成系统字体 | 中文 Google Fonts 没有 latin 分片，旧抓取方式拿不到；改文案后新字不在子集里 | `fetch_fonts.py --text-from promo.html "<字体>"`，文案改动后重跑 |
| 风格做成了“模板感” | 把风格的全部特效堆满全片 | 只取签名动作中的一两个用在关键处；全片一套转场语法；主体占画面三分之一以上 |
| 全片像幻灯片：每幕淡入，停住，淡出 | 动效只用了 `rise`（淡入+上移），幕间靠引擎交叉淡入；没有贯穿元素 | 选一个主角（圆点、消息卡、光标）贯穿五幕，换幕靠它位移或 `morphRect` 放大；`transition: 'none'`；用 `spring`、`travel`、`reel`、`riseChars` 等词汇，`rise` 只给次要文字 |
| 第 3 幕 15 秒是一张截图在框里 | 把“真实素材优先”理解成“截图就是原理” | 先用风格的原生动作演机制，截图在机制讲完后作证据停 ≥ 2 秒；见 `storyboard.md` |
| 画面节奏和配乐对不上 | 时间点手写（9.75、14.6），没有拍网格 | `const B = beats(bpm)`，所有切换、落定写成 `B(n)`；cues.json 里的 `t` 用同一网格 |
| `motion_check.py` 报 STILL | 某段 ≥ 2 秒几乎没有像素变化 | 给静止段加主角动作、`pulse` 呼吸或连接器 `dashFlow`；确认是“刻意停留给人读”的再忽略 |
| 风格化画面里真实素材看不清 | 素材被缩小、旋转或像素化以适配风格 | 素材放进“框中框”，正对镜头停留 ≥ 1.5 秒、宽度 ≥ 画面 45%；素材本身不加风格滤镜 |
| 竖屏关键文字被平台界面挡住 | 9:16 上下区域被标题栏、评论区覆盖 | 关键内容放在中间 76% 的安全区 |

## 自检

- [ ] `render.mjs` 无页面错误退出（字体、图片、脚本全部加载成功）
- [ ] 每幕至少一张静帧已人工查看：无残影、无溢出、无占位符
- [ ] 首帧是完整的第一幕，末帧停在安装画面
- [ ] `check_sync.py` 标出的每个嫌疑点都已看帧确认（已修复，或注明是误报）
- [ ] `ffprobe` 显示视频流与音频流，时长等于 `__duration`
- [ ] 安装命令与 README 原文一致，版本号与发布渠道核对过
- [ ] 所有素材的授权清楚：字体 OFL、音频为脚本合成或用户提供的授权音乐、截图来自本项目
- [ ] 风格签名在静帧上成立（不说明风格名也能认出），真实素材在风格化画面里清晰可读
- [ ] 贯穿主角在每一幕都能指出来；每个幕边界的帧条上看得到它的位移或变形，而不是淡入淡出
- [ ] `motion_check.py` 没有 STILL 段，或每个 STILL 段都注明是刻意停留
