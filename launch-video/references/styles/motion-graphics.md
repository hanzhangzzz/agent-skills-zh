# 商业动态图形

信息清楚、制作成本低，大多数开源工具的稳妥候选都在这一组。除特别说明外，全部用 DOM + SVG 完成，起点是 `assets/template.html`（editorial）或在空白页上调用 `engine.js`。

## editorial · 编辑部（默认模板）

- **签名**：米白纸底配衬线大标题，原理幕切到深色，用圆形扩散转场；角标与章节号作为画面内容出现。
- **五幕**：直接用 `assets/template.html` 和 `references/storyboard.md` 的视觉系统。
- **何时选**：严肃工具，证据以界面或文本为主；或者其他候选的试样质感都不过关时兜底。
- **声音**：`calm`；`click tick pop chime snap whoosh reveal type`。

## flat-motion · 扁平动态图形

- **签名**：纯色几何、零阴影、零渐变。元素用弹性缓动入场，图标出现时对应的数字同步滚动，一个小圆点贯穿全片当“主角”。
- **五幕**：
  - 痛点：小人或图标卡在重复劳动里，例如循环箭头、堆高的文件，代价用一个滚动数字说明。
  - 亮相：主角圆点弹开，变成 Logo 和名字。
  - 原理：每一步是一组“图标 → 箭头 → 结果卡”，结果卡里放真实截图（圆角卡片，占画面 50% 以上）。
  - 证据：大数字配一根柱子长高。
  - 行动：圆点变成命令行的光标。
- **转场**：主角圆点放大铺满画面变成下一幕的底色（color wipe），或沿路径滑到下一幕的位置。
- **实现**：SVG 图形 + `backOut` / `squash`；图标用 Lucide、Tabler（MIT）的 SVG 源码，内联到页面。
- **动效**：入场 `backOut(x, 1.4)`，时长 0.45–0.6 秒；同组元素间隔 80–120ms 依次弹出；落地用 `squash`。
- **色字**：一种主背景色、一种辅色、黑白，配高饱和撞色（例如 `#2F3BFF` 配 `#FFD23F`）；字体用 Space Grotesk、Bricolage Grotesque 或 Archivo Black，中文用 Noto Sans SC 700。
- **声音**：`bright`；`pop` 给每次弹出，`thud` 给大元素落地，`chime` 给结果出现。
- **穿帮**：所有元素回弹幅度相同会显得机械，大物体回弹小、小物体回弹大；阴影、渐变一旦出现就不再是扁平风。

## kinetic-type · 动态排版

- **签名**：文字本身就是画面。瑞士网格对齐，单词按节拍替换，文字沿圆环旋转，按字母做波浪错位，字号在 40px 到 400px 之间跳变。
- **五幕**：
  - 痛点：重复的词刷满屏，例如“regenerate regenerate regenerate”。
  - 亮相：所有词收拢成项目名。
  - 原理：每一步是一个动词大字，旁边小窗放真实终端或截图，占画面 40–50%。
  - 证据：数字占满整屏宽度。
  - 行动：命令原文按字符打出。
- **转场**：一个词放大穿过镜头，进入下一幕（zoom-through）；或者网格整体平移。
- **实现**：每个字母单独一个 span，在初始化时一次建好，`render(t)` 只改 transform；环形文字用 SVG `textPath` 加 `startOffset`。
- **动效**：卡拍切换，每拍换一个词；字母级错位 20–30ms；入场 `expoOut`。
- **色字**：黑白加一个强调色；字体用 Anton、Bebas Neue、Archivo Black 这类粗体压缩字，或 Instrument Serif 斜体做对比；中文用 Noto Sans SC 900。
- **声音**：`bright`（活泼）或 `pulse`（冷峻）；每次换词配 `tick`，大字落定配 `snap`。
- **穿帮**：同屏超过 2 种字体会很乱；中文字间距要比英文收紧；纯文字片要用真实素材小窗保证证据可见。

## isometric · 等轴 2.5D

- **签名**：无透视的等轴俯视（30° 投影），像微缩模型。地砖以波浪方式依次弹起，模块长高，传送带运送数据块。
- **五幕**：
  - 痛点：一块地砖上数据块堆积、卡住。
  - 亮相：整片城市或园区从中心波浪式长出，最后浮出项目名。
  - 原理：每个组件是一栋楼或一台机器，数据块沿传送带移动。每步结束时镜头推近，楼顶浮出真实截图卡片（正对镜头，不做等轴变形）。
  - 证据：楼的高度就是柱状图。
  - 行动：镜头拉远，看到整座城。
- **转场**：镜头在等轴平面上平移到下一片区域（同一个世界里推拉），不要切黑。
- **实现**：Canvas 2D 或 SVG，写一个 `iso(x, y, z) → [sx, sy]` 函数，所有绘制都经过它（一个世界坐标到屏幕的函数）。按 x+y 从后往前画（画家算法）。
- **动效**：地砖弹出用 `backOut`，延迟取 `(x + y) × 40ms` 形成波浪；传送带上的物体位置用 `(t × 速度) % 长度`。
- **色字**：同一色相三个明度给顶面、左面、右面（例如淡紫 `#E9E4FF`、`#C9BFF5`、`#A79BE0`）；强调色只给数据块。字体用 Space Grotesk 或 Inter Tight。
- **声音**：`bright`；地砖弹起配连续的 `tick`（只给前几块），楼长高配 `pop`，数据块到站配 `chime`。
- **穿帮**：三个面明度差太小会显得发平；遮挡顺序错误最常见，交付前看静帧逐一检查。

## data-news · 数据新闻

- **签名**：折线描出趋势，变形成柱状对比，再变成环形占比。数字滚动，注释用引线和小圆点标注。
- **五幕**：
  - 痛点：一条代价曲线持续上升（数据必须真实，否则标“示意”）。
  - 亮相：曲线拐弯，拐点处出现项目名。
  - 原理：每一步配一张真实输出或截图，侧栏写一行说明。
  - 证据：这是本风格的主场，核实过的数字依次以折线、柱状、环形呈现，脚注写来源、样本和条件。
  - 行动：命令原文。
- **转场**：上一张图的几何元素直接变成下一张图，例如折线的点变成柱子的顶。
- **实现**：SVG path；描线用 `stroke-dasharray` / `stroke-dashoffset` 按 `t` 计算；数字用 `Math.round(值 × cubic(p))`；图表数据只来自核实结果。
- **动效**：描线 0.8–1.2 秒，`cubic`；柱子长高 `expoOut`，间隔 100ms；引线在数字停稳后出现。
- **色字**：浅底或深底，一个强调色给“我们的”数据，其余用灰；数字用等宽字或 Inter Tight 的 tabular-nums。
- **声音**：`calm` 或 `pulse`；描线配 `whoosh`（轻），数字停稳配 `tick`，关键结论配 `chime`。
- **穿帮**：坐标轴不从 0 开始会夸大差异，必须标注；示意数据和真实数据不能放在同一张图里。

## ui-showcase · 产品界面演示

- **签名**：真实界面截成卡片依次入场，光标移动并点击（点击处出现波纹），通知从角落弹出，最后从浅色切到深色模式。
- **五幕**：
  - 痛点：旧流程的多个窗口杂乱堆叠，属于示意，不点名竞品。
  - 亮相：Logo 加一张主界面卡片放大。
  - 原理：真实录屏帧或截图，光标按真实操作路径移动，每步放大关键区域（类似 Ken Burns 推近）。
  - 证据：真实导出结果铺满。
  - 行动：命令原文或下载按钮。
- **转场**：从当前卡片放大进入下一张界面（shared element），或者整组卡片做 3D 翻转（CSS `perspective`，最大 25°）。
- **实现**：录屏转帧用 `setFrame`；光标是 SVG，位置在关键帧之间用 `cubic` 插值；点击波纹是缩放的圆。卡片阴影用两层：一层大而淡，一层小而实。
- **动效**：卡片入场 `expoOut`，从 0.94 缩放到 1，间隔 120ms；光标移动 0.5–0.7 秒，到位后停 0.15 秒再点击。
- **色字**：跟随产品界面；背景用产品主色的极淡版本或深灰，字体用 Inter Tight。
- **声音**：`calm`；点击配 `click`，通知配 `pop`，模式切换配 `whoosh`。
- **穿帮**：光标路径不能穿过界面上不存在的按钮；截图分辨率不够时宁可小一点，不要放大到糊。

## promo-sale · 电商促销（改造为“前后对比”）

开源项目没有价格，这个风格的语法用来讲“以前的代价 → 现在的代价”。

- **签名**：大字砸屏并伴随画面震动，原值划线后变成新值，标签像优惠券一样飞入，按钮呼吸闪动。
- **五幕**：
  - 痛点：“40 步”“3 小时”等大字砸下，数字必须真实可核实。
  - 亮相：项目名配爆炸放射线背景。
  - 原理：三张真实截图像商品卡一样排开，每张配一个“券”标签写出关键能力。
  - 证据：原值划线 → 新值（例如 `$12.40 → $7.44 / task`），旁边写脚注。
  - 行动：命令框像“立即购买”按钮一样呼吸。
- **转场**：放射线旋转加白闪（2 帧），或者大字砸下时直接盖住上一幕。
- **实现**：DOM；画面震动是给 `#stage` 加位移，幅度 `8px × exp(-衰减)`，从砸下那一帧开始；划线是 SVG 线从左往右生长。
- **动效**：砸屏从 1.6 倍缩放到 1，0.18 秒，`expoOut`，落地瞬间加 `squash`；呼吸按钮的缩放是 `1 + 0.04 × sin`。
- **色字**：红黄撞色或品牌色配黑；字体用 Anton、Archivo Black，中文用 ZCOOL QingKe HuangYou。
- **声音**：`bright`；砸屏配 `thud` + `snap`，券飞入配 `whoosh`，新值出现配 `chime`。
- **穿帮**：最容易沦为夸大宣传，“限时”“抢”这类词与开源无关，不要用；前后数字必须同一口径。

## whiteboard · 白板手绘

- **签名**：白板底，线条带轻微手抖，文字一笔一画写出，红笔圈出重点，一只手或笔尖跟着笔画移动（可选）。
- **五幕**：
  - 痛点：画一个卡住的流程图，红叉打在卡点上。
  - 亮相：手写项目名，下方划线。
  - 原理：每步画一个框和箭头，框里贴一张真实截图，像拍立得一样用胶带贴上。
  - 证据：手写大数字，红笔圈出。
  - 行动：命令原文用打印体出现在便签上，保证可读。
- **转场**：擦除，用板擦划过；或者镜头沿白板平移到下一块区域。
- **实现**：SVG path + `stroke-dashoffset` 描边。手抖做法：给路径顶点加 `rng(seed)` 生成的 ±1.5px 偏移，偏移量固定不随帧变。手写字用 Caveat、Kalam、Patrick Hand；中文用 Long Cang 或 Zhi Mang Xing。要让字一笔一画写出，可以把字体轮廓当作遮罩，按方向擦开，或者对关键字手画 path。
- **动效**：描线速度恒定（像真人画），每笔之间停 60–100ms；红圈画 1.1 圈，首尾不闭合。
- **色字**：白底 `#FBFBF8`，黑色 `#1E1E1E`，红色 `#E03A3A` 只用于圈重点，蓝色可作次要色。
- **声音**：`calm`；书写配连续轻 `tick`（马克笔声），圈重点配 `snap`。
- **穿帮**：所有线同时出现就不像手绘；手抖量随帧变化会让线条闪烁。

## sticker-explainer · 贴纸风科普

- **签名**：粗白描边的贴纸图形（白边 8–12px 加柔和投影），超大画布上镜头在各个贴纸之间移动，SVG 图表也做成贴纸。
- **五幕**：
  - 痛点：一个问题贴纸配一圈“？”小贴纸。
  - 亮相：项目名做成大贴纸“啪”地贴上。
  - 原理：项目的组成部件拆成贴纸，引线标注名称；真实截图也加白边做成贴纸。
  - 证据：数字贴纸配环形图贴纸。
  - 行动：命令贴在便签纸上。
- **转场**：镜头在超大画布上平移或缩放到下一组贴纸，用一个相机函数统一管理。
- **实现**：整个世界画在一个 4000×3000 的大容器里，相机就是对容器的 `translate + scale`；白边用 SVG `stroke` 或 CSS `filter: drop-shadow(0 0 0 #fff)` 叠多层。
- **动效**：贴上时从 1.25 缩到 1，同时旋转 ±4°，`backOut`；镜头移动 0.8–1 秒，`cubic`。
- **色字**：明亮的平涂色块配白边，背景用浅色纸；字体用 Fredoka、Baloo 2，中文用 ZCOOL KuaiLe。
- **声音**：`bright`；贴上配 `pop`，镜头移动配 `whoosh`。
- **穿帮**：贴纸太多就看不清，每屏的焦点只放一个。

## shape-morph · 形变动画

- **签名**：一个形状连续变成下一个形状，形状本身承担叙事，例如一滴墨变成咖啡杯，再变成太阳、海鸥。
- **五幕**：
  - 痛点：一个形状不断被打散、重来。
  - 亮相：形状最终变成 Logo。
  - 原理：每一步是一次形变，“输入形状 → 输出形状”。真实截图在形变结束后从形状内部显现，形状作为遮罩放大。
  - 证据：形状变成数字。
  - 行动：形状变成光标加命令。
- **转场**：形变本身就是转场，全片只有这一种。
- **实现**：两条 SVG path 重采样成同样数量的点（沿弧长取 128–256 个点），按 `t` 逐点插值。对齐两条路径的起点和方向，避免中途扭成麻花。
- **动效**：每次形变 0.6–0.9 秒，`cubic`；形变之间停 0.3 秒，让观众认出新形状。
- **色字**：单色形状配纯色背景，每次形变可以换背景色；字体极简，用 Inter Tight 或 Syne。
- **声音**：`calm`；形变开始配 `whoosh`，落定配 `pop`。
- **穿帮**：点数不足会出现棱角；起点不对齐会翻转；形状太复杂观众认不出来。

## bauhaus · 几何构成·包豪斯

- **签名**：只用圆、方、三角，配红 `#E03C31`、黄 `#F2C230`、蓝 `#1F4E9C`、黑和米白；严格 120px 网格，每拍落下一块，20 拍左右拼出一张海报。
- **五幕**：
  - 痛点：几何块错位、倒塌。
  - 亮相：几何块按节拍拼出项目名的字母。
  - 原理：每一步占网格中的一块区域，真实截图被裁成方形或圆形嵌在网格里。
  - 证据：数字用巨大的几何数字形式出现。
  - 行动：命令放在黑色横条上。
- **转场**：网格块按顺序翻转或滑出，露出下一幕。
- **实现**：DOM/SVG，所有坐标都是网格单位的整数倍；字母可以用几何块拼，也可以用 Archivo Black、Rubik Mono One。
- **动效**：严格卡拍（120 BPM 即每拍 0.5 秒），每拍一个动作；滑入 `expoOut`，0.25 秒，不回弹。
- **声音**：`pulse`（bpm 设为 120）；每块落下配 `tick`，成形配 `snap`。
- **穿帮**：颜色超出红黄蓝黑白就破功；不卡拍会显得随意。

## variety-captions · 综艺花字（9:16）

- **签名**：大字加粗描边（双层：白描边外面再加彩色描边），文字抖动、弹跳，配贴纸、emoji 风图标、放射线；花字本身就是内容。
- **五幕**：
  - 痛点：真实场景截图或录屏，配花字吐槽，如“又要重画？！”。
  - 亮相：项目名花字从天而降并弹跳。
  - 原理：竖屏上方放真实录屏（占 60% 高度），下方用花字解释每一步。
  - 证据：数字花字放大闪烁。
  - 行动：命令放在醒目的框里，旁边的花字写“复制就能用”。
- **转场**：快速推镜加白闪，或者花字横扫。
- **实现**：画布 1080×1920（`LV.start({ width: 1080, height: 1920 })`）；描边用 `-webkit-text-stroke` 叠 `paint-order: stroke fill`，或者多层 `text-shadow`；抖动幅度是 `sin(t × 40) × 3px`，只在入场后的 0.3 秒内出现。
- **动效**：从 1.5 倍缩小到 1 并 `squash`，0.25 秒；每句花字停留时间按阅读时间规则计算。
- **色字**：高饱和黄、粉、青配黑描边；中文用 ZCOOL KuaiLe、ZCOOL QingKe HuangYou，英文用 Fredoka、Bungee。
- **声音**：`bright`；每个花字配 `pop` 或 `blip`，重点配 `snap`。
- **穿帮**：竖屏的上下 12% 会被平台 UI 遮挡，关键内容放在安全区里；花字盖住真实录屏的关键区域。
