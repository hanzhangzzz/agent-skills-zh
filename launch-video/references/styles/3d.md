# 三维渲染

起点是 `assets/three-starter.html`：three.js 负责画 WebGL 层，标题、说明和真实截图放在上面的 DOM 层。工作目录先执行 `npm i three`；render.mjs 通过本机 HTTP 提供页面，ES module 可以正常加载。

## 三维共用规则

- **姿态只由 t 决定**：落体、回弹、环绕镜头都写成 t 的闭式函数（参考 starter 的 `fall` 和 `squash`）。不用物理引擎逐帧推进，不用 `OrbitControls`，不读 `clock.getDelta()`。
- **质感三件套**：主光（带软阴影）+ 轮廓光（从背后勾边）+ 环境反射。环境反射不用下载 HDRI，用 `RoomEnvironment` 生成：`scene.environment = new THREE.PMREMGenerator(renderer).fromScene(new RoomEnvironment(), .04).texture`（`three/addons/environments/RoomEnvironment.js`）。
- **超采样**：`renderer.setPixelRatio(2)`。成片约每秒渲染 6 帧，30 秒的片子大约 2–3 分钟。
- **真实素材进三维**：截图用 `TextureLoader` 贴在平面上（`colorSpace = THREE.SRGBColorSpace`、`toneMapped: false`，否则颜色会发灰）。平面要正对镜头停留至少 1.5 秒，让人看清。看不清的角度只用于过渡。
- **3D 文字**：优先用 DOM 叠加。Logo 或品牌字需要立体时，用 `SVGLoader` 读 SVG，再用 `ExtrudeGeometry` 挤出，不依赖 typeface 字体文件。
- **自定义着色器**（抽象形体、液态）：一个全屏平面 + `ShaderMaterial`，把 `uTime` 设成 t。同一个 t 必须得到同一张图，着色器里不要用依赖帧序的噪声种子。
- **颗粒感在 ffmpeg 里加**：需要胶片颗粒时，在合成阶段用 `noise=alls=6:allf=t` 滤镜，不在页面里逐帧画噪点（会让编码体积暴涨）。

## product-3d · 3D 产品渲染

- **签名**：主光、轮廓光、地面反射，镜头缓慢环绕；参数标注线从物体表面引出，数字在线的尽头出现。
- **五幕**：
  - 痛点：暗场中一个粗糙、破碎的物体，作为代价的隐喻。
  - 亮相：物体在聚光中旋转成型，镜头环绕 90°，项目名出现。
  - 原理：物体分解成三到四个部件（爆炸图），每个部件引出一根标注线，指向 DOM 层的真实截图卡片。
  - 证据：物体停在 3/4 视角，标注线指向核实过的数字。
  - 行动：镜头拉远，物体变小，下方出现命令。
- **转场**：镜头穿过物体表面，或推进到部件内部，进入下一幕。
- **主体从哪来**：项目没有实体时，从机制里取一个物件，例如“把图画对”可以是一块画板，“压缩上下文”可以是一个被压紧的方块。也可以把 Logo 挤出成立体。
- **实现**：`MeshPhysicalMaterial`（metalness 0.1–0.9，roughness 0.2–0.5，clearcoat 视材质而定）；地面反射用 `MeshStandardMaterial` 加低 roughness，或者 `ShadowMaterial` 加一个淡镜像。标注线是 DOM 层的 SVG 线，起点由 `vector.project(camera)` 换算到屏幕坐标，每帧计算。
- **动效**：环绕镜头整片只走 60–120°，`cubic`；爆炸图用 `expoOut`，部件间隔 100ms。
- **色字**：深灰或纯黑背景配一束暖光，强调色只用在标注线上；字体用 Inter Tight 或 Space Grotesk 的细字重。
- **声音**：`pulse`；部件分开配 `whoosh`，标注线出现配 `tick`，数字配 `chime`。
- **穿帮**：没有轮廓光，物体会融进背景；环境反射过强时像塑料镜面。

## clay · C4D 粘土风（Soft & Clay）

- **签名**：糖果色的哑光材质（roughness 0.8 以上），柔和大面积阴影，物体落地挤压再回弹，整体圆润、没有锐角。
- **五幕**：
  - 痛点：一堆软软的方块歪倒、塌掉。
  - 亮相：字母或 Logo 挤出成粘土块，一个个落下、挤压、回弹，站稳。
  - 原理：每一步是一个粘土小场景，例如方块滑进机器、变形后出来；真实截图像一张贴在粘土墙上的海报（DOM 卡片加圆角和柔和投影）。
  - 证据：数字由粘土柱长高表现。
  - 行动：命令框是圆角粘土按钮。
- **转场**：一个大粘土球滚过画面、填满屏幕，进入下一幕；或者地面整体倾斜，旧物体滑出。
- **实现**：基于 starter。几何体用 `RoundedBoxGeometry`（`three/addons/geometries/RoundedBoxGeometry.js`）、`CapsuleGeometry` 和球体，避免锐边。阴影：`PCFSoftShadowMap`，`shadow.radius` 设为 6–10，地面用浅色 `ShadowMaterial`，透明度 0.15–0.2。
- **动效**：下落是二次函数，落地时 `squash`（幅度 0.2–0.3），一组物体依次落下，间隔 120ms。镜头轻微俯视并缓慢推进。
- **色字**：粉 `#FF8FAB`、薄荷 `#7ED7C1`、奶黄 `#FFE08A`、淡紫 `#B9A7FF`，背景用其中一色的浅版；字体用 Fredoka、Baloo 2，中文用 ZCOOL KuaiLe。
- **声音**：`bright`；每次落地配 `thud`，小物件配 `pop`，成形配 `chime`。
- **穿帮**：材质太亮会像塑料，必须够哑；没有挤压回弹就成了普通 3D；阴影太硬会失去粘土感。

## abstract-3d · 抽象 3D 形体

- **签名**：由数学函数定义的形体，例如球体之间平滑融合、扭结、超形状，持续旋转变形，表面是珠光或虹彩材质。
- **五幕**：
  - 痛点：形体抖动、断裂、不规则，象征混乱。
  - 亮相：形体融合成一个光滑的整体，项目名浮在前面（DOM）。
  - 原理：每一步形体变成一种新形态，旁边是真实截图卡片，形体缩到画面一侧作为背景。
  - 证据：形体的分裂数或体积映射到数字，数字必须真实。
  - 行动：形体收成一个小球，停在命令旁边。
- **转场**：形体放大占满全屏，颜色变成下一幕的背景色。
- **实现**：方案一是全屏平面 + 光线步进着色器（raymarching）：SDF 用 `smin` 做平滑融合，法线用有限差分，珠光用 `cos(调色板 × 法线点积)` 生成虹彩。方案二是高细分球体，在顶点着色器里按 `sin(position × 频率 + uTime)` 位移，配 `MeshPhysicalMaterial` 的 `iridescence`。
- **动效**：形变缓慢连续（周期 4–8 秒），关键节拍时加速一次。
- **色字**：深底配珠光高光，或浅底配奶油色形体；字体用 Syne、Unbounded。
- **声音**：`pulse`；形态切换配 `whoosh`，融合完成配 `reveal`。
- **穿帮**：raymarching 步数不够时边缘会出现条纹，步数设到 96 以上，并在静帧上检查；形体始终和产品无关时，只能作背景，不能当主角。

## low-poly · 低多边形

- **签名**：程序生成的低多边形地形，平直着色（每个面一个颜色），按高度上色（水、沙、草、岩、雪），远处有雾。
- **五幕**：
  - 痛点：起伏混乱的地形，看不到路。
  - 亮相：镜头飞越山谷，项目名出现在天空。
  - 原理：一条发光的路径沿地形铺开，每个节点是一步；节点处立起一块广告牌，上面是真实截图（正对镜头）。
  - 证据：山峰的高度就是数据，峰顶标数字。
  - 行动：镜头升到高空俯视全图，命令出现。
- **转场**：镜头沿路径飞到下一个节点，同一个世界里连续运动。
- **实现**：`PlaneGeometry` 细分 80×80，顶点高度用种子噪声（自己写 value noise，或者用 `three/addons/math/SimplexNoise.js` 加固定种子）；`flatShading: true`；顶点颜色按高度阈值设置；`scene.fog = new THREE.Fog(颜色, 近, 远)`。
- **动效**：镜头沿 `CatmullRomCurve3` 移动，`getPointAt(cubic(p))`。
- **色字**：柔和自然色或日落渐变，雾色与天空色相同；字体用 Inter Tight。
- **声音**：`calm`；节点出现配 `chime`，飞越配 `whoosh`。
- **穿帮**：雾色和背景色不一致会露出地形边缘；面数太多就不再“低多边形”。

## space · 星际空间

- **签名**：程序生成的气态行星，带状云层自转，星云背景，星点有视差；跃迁时星点拉成线。
- **五幕**：
  - 痛点：飞船（或光点）在小行星带里艰难穿行。
  - 亮相：跃迁，星点拉成光线，停下时巨大的行星占据画面，项目名出现。
  - 原理：每一步是一颗卫星或空间站，真实截图像全息投影一样浮在旁边（DOM 卡片，加发光边和轻微扫描线）。
  - 证据：轨道的数量或大小对应数据。
  - 行动：行星缓慢自转，下方出现命令。
- **转场**：跃迁（星点从中心向外拉伸成线），全片统一使用。
- **实现**：行星用球体加着色器：按纬度 `sin(y × 频率 + 噪声)` 生成色带，经度方向加 `uTime` 让云层旋转，大气用菲涅耳边缘发光。星点：`Points`，位置用种子随机；跃迁时在着色器里沿视线方向拉长。
- **动效**：行星自转很慢（一圈 60 秒以上）；跃迁 0.6–0.8 秒，`expoOut`。
- **色字**：深蓝黑背景，行星用两三种相近色；字体用 Orbitron 或 Space Grotesk。
- **声音**：`pulse`；跃迁配 `whoosh` + `reveal`，全息卡片出现配 `blip`。
- **穿帮**：星点每帧随机会闪烁，位置必须固定；行星色带太规则会像条纹球。
